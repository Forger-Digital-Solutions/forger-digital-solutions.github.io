ForgerEMS began with USB toolkit work, but that is no longer an accurate description of the whole application.

The public `v1.2.3-preview.1` release brings USB Builder, Drive Validator, USB and port intelligence, vendor-first driver guidance, system information, battery health, and local-first Kyra assistance into one Windows workbench.

Its safety boundaries matter as much as the feature list. Validation modes avoid the Windows system drive and do not claim direct NAND inspection. Driver guidance opens official vendor sources rather than silently installing packages. Reports and assistant context remain local unless the user explicitly chooses to share them.

Repository development has continued beyond that package, including work on Dr. Forge integration and deeper toolkit management. Those changes are active development, not capabilities attributed to the downloadable `v1.2.3-preview.1` build.

The website links to the [canonical GitHub Releases page](https://github.com/Forger-Digital-Solutions/ForgerEMS/releases), where the public version, assets, release notes, and checksums can be verified together.
